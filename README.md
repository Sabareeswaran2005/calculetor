# 🧮 Modern Calculator

A modern and responsive calculator web application with a clean user interface and calculation history.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Percentage calculation
- 🔄 Positive / Negative toggle
- 🗑️ Clear and delete functions
- 🕘 Calculation history
- 🌙 Dark / Light mode
- 📱 Responsive design
- 📋 Copy result option

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
